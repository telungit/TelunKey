## キーで直行

トリガーキー（左右の Command、左右の Option、または Space）を押したまま、アプリに割り当てた 1〜3 個のキーを入力します。アプリが起動していなければ開き、ウインドウがひとつなら前面に表示し、複数ならセレクタを表示します。トリガーキーを押している間は割り当ての一覧を確認できます。

<img src="./images/en/hint.png" width="100%" alt="トリガーキーを押している間に割り当てを一覧表示するヒントメニュー" />

## キー配置セレクタ

セレクタではウインドウのサムネイルをキーボード順（1–0、Q–P、A–L、Z–M）に並べ、1 ページに最大 36 個表示します。対応する数字や文字のキーで選択します。

- スペース：最後に使ったウインドウへ
- 別のデスクトップにあるウインドウはそのデスクトップを表示
- [ と ] でページ送り、Esc でキャンセル、クリックでも選べます

<img src="./images/en/picker.png" width="100%" alt="ウインドウセレクタ" />

## トリガージェスチャー

トリガーキーを押しながら、有効にした1本・2本・3本指でスワイプし、ポインタ下のウインドウを半分、4分の1、または最大化して配置します。

- 上下左右：半分。斜め 4 方向：4 分の 1
- 指を離さず上から下へ：最大化（メニューバーと Dock は残す）
- キャンセル領域に入ればキャンセル、戻せば選び直し

## 3本指・4本指のグローバルジェスチャー

トリガーキーは不要。3本指のスワイプと往復、3本または4本指のタップ、ダブルタップ、物理クリックに、ショートカット、単一キー、中クリック、ウインドウ操作を割り当てられます。長押しは画面間移動専用です。 操作対象は、ポインタ下で固定されたウインドウです。

新規インストールではオン、アップグレード時は既存の設定を保持します。長押しは画面間移動専用で、ほかのジェスチャーは変更可能。練習では実行せずプレビューします。

3本指スワイプや長押しによる画面選択を使う前に、システムの3本指ドラッグをオフにし、横・縦スワイプを4本指に変更するかオフにしてください。TelunKey は有効な競合だけを表示し、「トラックパッド → その他のジェスチャ」または「アクセシビリティ → ポインタコントロール → トラックパッドオプション」へ案内します。戻ると自動で再確認し、あとで設定することもできます。解決するまで3本指スワイプと長押しは動作せず、タップとクリックは引き続き使えます。システムの調べる機能との競合は別に表示します。システム設定を自動で変更することはありません。

## 長押しで画面間移動

左、右、それとも上？長押しで macOS の画面配置に沿ったマップを表示。移動先へスライドし、指を離すとウインドウが移動します。

- 4本指で長押ししてからスライドして画面を選択。設定後の3本指、またはトリガーキーを押しながら有効な1〜3本指でも使えます
- 画面配置に沿って選択し、各画面の使用可能領域に対する比率でウインドウを配置
- 確定前は戻れます。元の画面や空白で指を離すとキャンセル。Esc でもキャンセルできます。

通常の4本指スワイプは macOS が処理します。まず4本指を動かさず長押しし、画面選択が始まってから今回のジェスチャーだけを一時的に受け持ちます。指を離すとシステムに戻ります。

別のディスプレイで現在表示中のデスクトップに移動できます。1台だけでは移動先がありません。フルスクリーンのウインドウと、フルスクリーンアプリを表示中の移動先は対象外です。元の画面、空白、利用できない画面で離すとキャンセル。トリガーキーは指を離すまで押し続け、先に離すとキャンセルになります。

## はじめる

macOS 14 以降と [Homebrew](https://brew.sh/) が必要です：

```bash
brew install --cask telungit/tap/telunkey
```

初回起動時にセットアップガイドが表示され、権限、トリガーキー、ショートカット、ジェスチャの設定を案内します。アップデートはアプリ内から、または次のコマンドで：

```bash
brew upgrade --cask --greedy telungit/tap/telunkey
```

## 権限

| 権限 | 用途 |
| --- | --- |
| アクセシビリティ（必須） | トリガーキーとジェスチャの検出、ウインドウの切り替えと配置 |
| 画面収録（任意） | ウインドウのサムネイル。未許可でもアプリアイコンを表示し、切り替えは可能 |
