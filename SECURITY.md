# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.1   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of TelunKey seriously. If you discover a security vulnerability or potential threat in TelunKey or its distribution pipeline, please report it privately:

1. **Telegram**: Reach out directly to [@telungram](https://t.me/telungram)
2. **GitHub Security Advisory**: Open a private advisory under the Security tab of this repository.

Please do not open public issues for sensitive security vulnerabilities until they have been reviewed and addressed. We appreciate your responsible disclosure and will respond within 48 hours.
