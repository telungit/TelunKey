## مفاتيح مباشرة

اضغط مع الاستمرار على مفتاح التفعيل (Command الأيسر / الأيمن أو Option الأيسر / الأيمن أو مفتاح المسافة)، ثم اضغط من مفتاح إلى ثلاثة مفاتيح معيّنة للتطبيق. إذا لم يكن التطبيق مفتوحًا فسيُفتح؛ وإذا كانت له نافذة واحدة فستظهر في المقدمة؛ وإذا كانت له عدة نوافذ فسيظهر المحدِّد. تظهر جميع التعيينات أثناء الضغط على مفتاح التفعيل.

<img src="./images/en/hint.png" width="100%" alt="قائمة التلميحات تعرض جميع الاختصارات أثناء الضغط على مفتاح التفعيل" />

## محدِّد لوحة المفاتيح

يرتب المحدِّد صور النوافذ المصغّرة وفق لوحة المفاتيح: 1–0، Q–P، A–L، Z–M، حتى 36 نافذة في الصفحة. اضغط الرقم أو الحرف المقابل لاختيار نافذة.

- المسافة: العودة إلى آخر نافذة استخدمتها
- نوافذ سطوح المكتب الأخرى تُظهر سطح المكتب الذي توجد فيه
- [ و ] لتقليب الصفحات، وEsc للإلغاء، أو انقر مباشرة

<img src="./images/en/picker.png" width="100%" alt="محدِّد النوافذ" />

## إيماءات التفعيل

اضغط مع الاستمرار على مفتاح التفعيل ومرّر بإصبعين على لوحة التعقب لوضع النافذة تحت المؤشر في نصف الشاشة أو ربعها أو تكبيرها.

- أعلى وأسفل ويسار ويمين: الأنصاف. الاتجاهات القطرية الأربعة: الأرباع
- إلى الأعلى ثم الأسفل دون رفع الأصابع: تكبير مع إبقاء شريط القائمة وDock
- ادخل منطقة الإلغاء لتلغي، وعُد لتختار من جديد

### إيماءات الأصابع الثلاث

بعد التفعيل، يمكن لكل من الاتجاهات الثمانية والتمرير ذهابًا وإيابًا والنقر والنقر المزدوج واللمس الطويل والضغط أن يرسل اختصارًا أو مفتاحًا واحدًا أو نقرة وسطى أو إجراء نافذة.

- متوقفة افتراضيًا. إذا تعارضت مع إيماءة نظام بثلاثة أصابع، تعرضها الإعدادات مع رابط للحل
- بين الشاشات: واصل الإيماءة بثلاثة أصابع إلى الخارج بعد منطقة الإلغاء لنقل النافذة إلى شاشة أخرى مع الحفاظ على تناسبها.
- يمكن إعادة تعيين كل إيماءة، ويتيح وضع التدريب معاينة الإجراءات دون تنفيذها.

## البدء

يتطلب macOS 14 أو أحدث و[Homebrew](https://brew.sh/):

</div>

```bash
brew install --cask telungit/tap/telunkey
```

<div dir="rtl">

عند التشغيل الأول يرشدك مساعد الإعداد خلال الأذونات ومفاتيح التفعيل والاختصارات والإيماءات. حدّث التطبيق من داخله، أو نفّذ:

</div>

```bash
brew upgrade --cask --greedy telungit/tap/telunkey
```
