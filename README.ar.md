# TelunKey

**من لوحة المفاتيح إلى أي نافذة، وبإيماءة إلى مكانها.**

اضغط مع الاستمرار على مفتاح واحد واكتب حرفًا أو حرفين لتصل مباشرة إلى أي نافذة في أي تطبيق. مرّر على لوحة التعقب، فتستقر النافذة في مكانها.

## مفتاحان أو ثلاثة إلى أي تطبيق

اضغط مع الاستمرار على مفتاح التشغيل (Command الأيسر / الأيمن أو Option الأيسر / الأيمن أو مفتاح المسافة) واكتب من حرف إلى ثلاثة أحرف. إن لم يكن التطبيق مفتوحًا فسيُفتح، وإن كانت له نافذة واحدة فستظهر في المقدمة، وإن كانت له عدة نوافذ فسيظهر منتقي النوافذ. وطوال ضغطك على المفتاح تُعرض جميع الاختصارات، فلا حاجة إلى حفظ شيء.

<img src="./images/en/hint.png" width="100%" alt="قائمة التلميحات تعرض جميع الاختصارات أثناء الضغط على مفتاح التشغيل" />

## اختر النافذة بنظرة واحدة

يعرض المنتقي جميع نوافذ التطبيق كصور مصغّرة. اضغط رقمًا أو حرفًا لاختيار نافذة، أو مفتاح المسافة للعودة إلى آخر نافذة مستخدمة. وإذا توزعت النوافذ على عدة سطوح مكتب، تُظهر كل بطاقة السطح الذي توجد عليه.

<img src="./images/en/picker.png" width="100%" alt="منتقي النوافذ مع الصور المصغّرة" />

## مرّر، فتستقر النافذة في مكانها

- **إيماءات التشغيل**: اضغط مع الاستمرار على مفتاح التشغيل ومرّر على لوحة التعقب لوضع النافذة الموجودة تحت المؤشر في نصف الشاشة أو ربعها أو ملئها.
- **الإيماءات العامة**: اربط التمرير أو النقر أو الضغط بثلاثة أصابع بإجراءات النوافذ أو اختصارات لوحة المفاتيح أو مفاتيح منفردة.
- **عبر الشاشات**: امضِ بالإيماءة العامة إلى ما بعد الحافة لنقل النافذة إلى شاشة أخرى مع الحفاظ على تناسبها.
- يمكن إعادة تعيين كل إيماءة، ويتيح وضع التدريب معاينة الإجراءات دون تنفيذها.

## البدء

يتطلب macOS 14 أو أحدث و[Homebrew](https://brew.sh/):

</div>

```bash
brew install --cask telungit/tap/telunkey
```

<div dir="rtl">

عند التشغيل الأول يرشدك مساعد الإعداد خلال الأذونات ومفاتيح التشغيل والاختصارات والإيماءات. حدّث التطبيق من داخله، أو نفّذ:

</div>

```bash
brew upgrade --cask --greedy telungit/tap/telunkey
```

## الأذونات والخصوصية

| الإذن | الاستخدام |
| --- | --- |
| تسهيلات الاستخدام (مطلوب) | التعرّف على مفاتيح التشغيل والإيماءات، وتبديل النوافذ وترتيبها |
| تسجيل الشاشة (اختياري) | الصور المصغّرة للنوافذ؛ ومن دونه تُعرض أيقونات التطبيقات ويظل التبديل يعمل |

تُحفظ الإعدادات على جهاز Mac، وبيانات الترخيص في سلسلة المفاتيح. لا يتصل TelunKey بالإنترنت إلا للتحقق من الترخيص والبحث عن التحديثات، ولا يجمع أي بيانات استخدام.
