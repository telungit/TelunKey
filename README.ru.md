# TelunKey

**С клавиатуры — к любому окну. Жестом — на нужное место.**

## Две-три клавиши до любого приложения

Удерживайте клавишу-триггер (левую / правую Command, левую / правую Option или пробел) и наберите от одной до трёх букв. Если приложение не запущено, оно откроется; если у него одно окно, оно выйдет на передний план; если окон несколько, появится окно выбора. Пока клавиша удерживается, на экране видны все назначения, так что запоминать ничего не нужно.

<img src="./images/en/hint.png" width="100%" alt="Меню подсказок со всеми назначениями при удержании клавиши-триггера" />

## Нужное окно с первого взгляда

Окно выбора показывает все окна приложения в виде миниатюр. Нажмите цифру или букву, чтобы выбрать окно, или пробел — чтобы вернуться к последнему использованному. Если окна разбросаны по нескольким рабочим столам, на каждой карточке указан рабочий стол.

<img src="./images/en/picker.png" width="100%" alt="Окно выбора с миниатюрами" />

## Проведите — и окно на месте

- **Жесты-триггеры**: удерживая клавишу-триггер, проведите по трекпаду, чтобы разместить окно под указателем на половину, четверть или весь экран.
- **Глобальные жесты**: назначьте смахиваниям, касаниям и нажатиям тремя пальцами действия с окнами, сочетания клавиш или отдельные клавиши.
- **Между дисплеями**: доведите глобальный жест за край, чтобы перенести окно на другой дисплей с сохранением пропорций.
- Любой жест можно переназначить, а режим тренировки показывает действия, не выполняя их.

## Начало работы

Нужны macOS 14 или новее и [Homebrew](https://brew.sh/):

```bash
brew install --cask telungit/tap/telunkey
```

При первом запуске мастер настройки проведёт вас через разрешения, клавиши-триггеры, сочетания и жесты. Обновляйтесь прямо в приложении или командой:

```bash
brew upgrade --cask --greedy telungit/tap/telunkey
```

## Разрешения и конфиденциальность

| Разрешение | Зачем |
| --- | --- |
| Универсальный доступ (обязательно) | Распознавание клавиш-триггеров и жестов; переключение и размещение окон |
| Запись экрана (по желанию) | Миниатюры окон; без него показываются значки приложений, переключение работает |

Настройки хранятся на вашем Mac, данные лицензии — в связке ключей. TelunKey выходит в сеть только для проверки лицензии и поиска обновлений и не собирает данные об использовании.

## Бесплатно и по лицензии

Бесплатная версия позволяет назначить до 5 приложений, все остальные функции доступны. Бессрочная лицензия на [сайте](https://www.telunkey.shop) снимает ограничение.
